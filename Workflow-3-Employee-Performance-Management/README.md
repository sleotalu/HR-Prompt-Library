# Workflow 03 - Employee Performance Management

**Business Function:** Human Resources (HR)\
**Trigger:** A scheduled employee performance review or a manager identifies a need to provide performance feedback and development support\
**Prompts in this section:** P08, P09, P10

## Section Purpose 
This section supports HR and managers in managing employee performance and professional development. It helps identify employee strengths and improvement areas, create structured development plans and review progress towards performance goals.
