# Workflow 01 - Recruitment

**Business Function:** Human Resources (HR)\
**Trigger:** A new position becomes available or the organisation identifies a need to recruit and select a suitable candidate\
**Prompts in this section:** P01, P02, P03, P04

## Section Purpose
This section supports HR in managing the recruitment and selection process from creating a job description through to communication with candidates. It helps HR prepare consistent job advertisements, screen applications, organise interviews and communicate professionally with applicants throughout the recruitment process.

