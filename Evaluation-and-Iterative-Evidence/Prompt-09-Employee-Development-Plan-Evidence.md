# Prompt 09: Employee Development Plan

## 1. Overview
This document record the iterative development of Prompt 09 - Employee Development Plan. The prompt was refined through three versions to improve quality, structure and usefulness of employee development plans. The iterations focused on establishing basic development planning structure, identifying employee skill gaps and development goals, and improving final prompt by including achievable goals, suitable activities, timeframes, measurable outcomes and progress monitoring.

## 2. Version History
| Version | Changes Made | Reason |
|---|---|---|
| V1.0 | Initial employee development plan prompt created. | Establish the basic employee development planning structure. |
| V1.1 | Added instructions to identify skills gaps, establish development goals and recommend suitable learning activities. | Improve the relevance and usefulness of development plans. |
| V1.2 | Added measurable outcomes, realistic timeframes and safeguards against unsuitable recommendations. | Improve development planning reliability and ensure appropriate HR oversight. |

## 4. Prompt Versions

### Version 1.0 - Initial Prompt
``` text
You are an experienced HR assistant responsible for helping managers prepare employee development plans to support workplace performance and professional growth.

Review the employee's performance information and identify areas where further development may be beneficial. Prepare a basic development plan with suitable recommendations for improvement.

Use the following information:
- Company name: [COMPANY_NAME]
- Employee name: [EMPLOYEE_NAME]
- Job title: [JOB_TITLE]
- Department: [DEPARTMENT]
- Manager name: [MANAGER_NAME]
- Performance information: [PERFORMANCE_INFORMATION]
- Development needs: [DEVELOPMENT_NEEDS]

Include the following sections:
1. Employee details
2. Current performance summary
3. Areas for development
4. Suggested development activities
5. Recommended next steps

Tone: supportive, constructive and professional.

Output: Generate a structured employee development plan using clear headings and concise explanations.

Do not include: invented employee information, unsupported assumptions or unrealistic development recommendations.
```

### Version 1.2 - Improved
``` text
You are an experienced HR employee development assistant responsible for helping managers create structured employee development plans to support workplace performance and professional growth.

Review the employee's performance feedback and development needs. Identify skill gaps and create a development plan with achievable goals, suitable activities, timeframes and measurable outcomes.

Use the following information:
- Company name: [COMPANY_NAME]
- Employee name: [EMPLOYEE_NAME]
- Job title: [JOB_TITLE]
- Department: [DEPARTMENT]
- Manager name: [MANAGER_NAME]
- Performance feedback: [PERFORMANCE_FEEDBACK}
- Identified development needs: [DEVELOPMENT_NEEDS]
- Employee career goals: [CAREER_GOALS]
- Available training and resources: [AVAILABLE_RESOURCES]

Include the following sections:
1. Employee details and current performance summary
2. Identified skill gaps and improvement areas
3. Employee development goals
4. Recommended training and development activities
5. Suggested timeframes
6. Required resources and support
7. Measurable success indicators and expected outcomes
8. Progress monitoring and follow-up arrangements

Tone: supportive, constructive and professional

Output: Generate a structured employee development plan. using a table to organise goals, activities, timeframes and expected outcomes.

Do not include: invented skill gaps, unsupported assumptions or unrealistic development goals.
```

## 5. Summary of Improvements

### V1.0 to V1.1
- Added instructions to identify employee skill gaps and development needs
- Introduced development goals to make the plan more focused
- Included suitable training and learning activities
- Added available resources to support employee development
- Improved the relevance of recommendations by linking them to performance feedback

### V1.1 to V1.2
- Added employee career goals to connect development activities with professional growth
- Expanded the plan to include achievable development goals and suggested timeframes
- Introduced measurable success indicators and expected outcomes
- Added progress monitoring and follow-up arrangements
- Required the output to use a table to organise goals, activities, timeframes and expected outcomes
- Improved the overall structure to make development plans easier for managers to implement and monitor

## 6. Final Outcome
Version 1.1 was selected as the final prompt because it provides a more complete and practical approach to employee development planning. It uses performance feedback and identified development needs to establish relevant goals, recommend suitable learning activities and set achievable timeframes. The final version also includes measurable outcomes and progress monitoring arrangements, allowing managers to review employee development and identify whether the planned activities are supporting workplace performance and professional growth.

The prompt also instructs the AI to avoid invented skill gaps, unsupported assumptions and unrealistic development goals. This support more relevant and reliable development plans.
