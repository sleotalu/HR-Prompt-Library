# Evaluation and Iterative Evidence

## 1. Overview
This folder contains the evaluation and iterative development evidence for the HR Prompt Library. It documents how the ten HR prompts were developed, tested and refined to improve their effectiveness, consistency and relevance across the three HR workflows.

Each prompt went through three versions (V1.0, V1.1 and V1.2). The iterations involved reviewing the prompt structure, improving instructions, refining input requirements and strengthening the expected output.

## 2. Purpose
The purpose of this folder is to:
- Document the development of each HR prompt across three versions provided
- Provide evidence of prompt testing and iterative improvements between at least two versions
- Compare at least one of the earlier prompt versions to the final versions
- Explain the changes made and reasons for each improvement
- Demonstrate how the prompts support practical HR tasks
- Maintain a record of prompt development for future review and improvement

## 3. Iteration Process
Each prompt followed a three-version development process:

| Version | Description |
|---|---|
| V1.0 – Initial Prompt | Established the initial prompt structure, role, task and expected output. |
| V1.1 – Improved Prompt | Introduced additional instructions, information requirements and improvements to the prompt structure. |
| V1.2 – Final Prompt | Refined the prompt to provide clearer instructions, more structured outputs and relevant safeguards for the HR task. |

The iterative process focused on improving prompt clarity, accuracy, consistency and suitability for the intended HR workflow and task.

## 4. Prompt Evaluation
The prompts were evaluated used the following criteria:

| Evaluation Criteria | Purpose |
|---|---|
| Accuracy | Checks whether the generated output addresses the task and uses the information provided. |
| Consistency | Assesses whether the prompt produces clear and consistently structured outputs. |
| Business Fit | Evaluates whether the output is relevant and suitable for the intended HR process. |
| Clarity | Checks whether the instructions and expected outputs are clear and understandable. |
| Risk and Reliability | Reviews whether the prompt avoids unsupported assumptions, invented information and inappropriate HR decisions. |

Testing and evaluation evidence should be used to identify areas requiring improvement before selecting the final prompt version.

- Overview of the prompt development process
- Version history showing changes made from V1.0 to V1.2
- Version comparison screenshots between one chosen earlier prompt to the final chose prompt
- A link to the final prompt chosen (All prompts V1.2 except for Prompt 09 being V1.1)
- Earlier prompt versions (V1.0 and V1.1)
- A link to the final prompt chosen

## 8. Final Outcome
The evaluation and iterative development process helped refine the ten HR prompts to better support recruitment, employee complaints and employee performance management. The final prompts aim to produce clear, structured and relevant outputs while maintaining appropriate HR safeguards. The evidence also supports ongoing review and improvement of the prompt library as organisational needs change.
