# HR Prompt Library: Workflow Automation

## 1. Project Overview
This project develops a structured AI prompt library designed to support Human Resources (HR) operations. The library uses Large Language Models (LLMs) to assist with repetitive administrative tasks, improve efficiency, standardise communication and support HR decision-making.

## 2. Business Objectives
- Reduce time spent on repetitive HR tasks.
- Improve consistency in HR processes.
- Support clear and professional communication
- Maintain privacy, fairness and human oversight

## 3. Workflow Overview

### Workflow 1: Recruitment 
Prompts 1-4 support recruitment and candidate management.

### Workflow 2: Employee Complaints
Prompts 5-7 support complaint handling.

### Workflow 3: Performance Management
Prompts 8-10 support performance reviews and employee development.
